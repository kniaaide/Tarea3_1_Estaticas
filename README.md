# Tarea3_1_Estaticas

Proyecto académico en C# sobre **estructuras de datos estáticas**.

## Contenido

Incluye implementaciones de pilas y colas estáticas, entre ellas una cola simple y una cola circular. También cuenta con una interfaz gráfica para explorar las estructuras y visualizar arreglos.

## Requisitos

- Visual Studio con soporte para C# y Windows Forms.
- .NET compatible con `Tarea3_1_Estaticas.csproj`.

## Ejecución

Abre `Tarea3_1_Estaticas.sln` en Visual Studio y ejecuta el proyecto.

## Propósito

Practicar la representación y las operaciones básicas de estructuras de datos estáticas.
